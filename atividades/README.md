# Atividades da disciplina

Pasta destinada aos notebooks e exercícios de Sistemas Inteligentes desenvolvidos antes do projeto final. Os notebooks ainda serão adicionados.

## Salvar um notebook do Colab no GitHub

1. Abra o notebook no Google Colab.
2. Selecione **Arquivo → Salvar uma cópia no GitHub** e autorize a integração, se solicitado.
3. Escolha o repositório `jukagoncalves/sistemas-inteligentes` e a branch `main`.
4. No campo do caminho do arquivo, use um nome como `atividades/atividade-01.ipynb`.
5. Escreva uma mensagem que descreva a atividade e confirme o envio.

Repita para os demais notebooks com nomes diferentes. Para incluir arquivos auxiliares, você também pode criar uma subpasta por atividade, como `atividades/atividade-01/notebook.ipynb`.

O envio do notebook não inclui automaticamente arquivos de dados armazenados no Google Drive. Documente a origem e as instruções de acesso aos dados necessários.

Alternativamente, baixe o notebook pelo menu **Arquivo → Fazer download → Fazer download do .ipynb** e envie o arquivo pela página desta pasta no GitHub, em **Add file → Upload files**.

Depois de salvar pelo Colab ou pelo site do GitHub, atualize sua cópia local com `git pull --ff-only` antes de fazer novas alterações locais.

Referência: [Integração oficial entre Colab e GitHub](https://github.com/googlecolab/colabtools/blob/main/notebooks/colab-github-demo.ipynb).
